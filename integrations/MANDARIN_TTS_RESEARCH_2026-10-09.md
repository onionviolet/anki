# Mandarin TTS research, October 9, 2026

Status: researched recommendations, not an accepted provider change. Official documentation and public source were inspected. No alternative engine was installed, no paid synthesis was called, and no collection or template was changed during this research. No listening comparison was performed.

Follow-up: the user selected **O3 Qwen3-TTS** as a free local implementation. The [Qwen adapter](qwen_tts/README.md) now has source, an installed isolated runtime, a generated sample and passing synthetic reviewer evidence. The cloud recommendations below retain their research status; the daily app and collection were not migrated by that implementation.

## Gap and recommendation

The incumbent is macOS system speech. The fork now chooses Tingting/Tian-Tian for Mandarin instead of using the alphabetical voice fallback, but this still leaves pronunciation decisions to Apple's engine. The remaining goal is accurate tones and intended readings for vocabulary and example sentences, with a natural standard Mandarin voice.

My recommendation is to trial **O1 MiniMax Speech 2.8 HD** and **O2 CosyVoice 3** with the same short pronunciation test before replacing card audio. Both document ways to specify an intended reading. **O3 Qwen3-TTS** is the local Mac candidate if avoiding ongoing API usage matters. These are fit judgments based on documented controls and integration cost, not a demonstrated sound-quality ranking.

## Provider distinctions that affect the choice

**F1: Correct-reading controls are the main improvement.** MiniMax documents pinyin syllables with tone numbers 1–5, and CosyVoice documents per-word pinyin fixes. An adapter could use the note's existing pinyin to resolve ambiguous headword readings without rewriting the displayed field. This is a proposed integration, not implemented behavior. Full-sentence audio needs context-aware handling of neutral tones and tone sandhi; citation-tone pinyin should not be blindly applied to every character.

**F2: CosyVoice region and model versions matter.** The inspected simple HTTP endpoint is Beijing-only. Singapore supports `cosyvoice-v3-plus` and `cosyvoice-v3-flash` through the documented streaming route; its voice and pronunciation features need verification on the chosen account and endpoint. Cloud `cosyvoice-v3.5-plus`/Flash are newer Beijing-only options without system voices, so cloning/design setup makes them less convenient for a first vocabulary trial. Use the voice list for the exact model and region. [Region/protocol guide](https://www.alibabacloud.com/help/en/model-studio/realtime-tts-user-guide), [voice samples](https://help.aliyun.com/en/model-studio/cosyvoice-voice-list)

**F3: HyperTTS's Alibaba integration is not CosyVoice.** Its inspected service calls the older `nls-gateway-ap-southeast-1.aliyuncs.com/stream/v1/tts` endpoint with ISI app/access keys. Modern Model Studio uses a different API and model/voice configuration. MiniMax, CosyVoice Model Studio, Qwen3, Fish and Doubao were not present as named services in the inspected main and community service trees. A custom extension is a documented route. [Alibaba implementation](https://github.com/Vocab-Apps/anki-hyper-tts/blob/05007b9a0982f18fd6e679ce651fe356074f1dbe/hypertts_addon/services/service_alibaba.py), [extension mechanism](https://github.com/Vocab-Apps/anki-hyper-tts-extensions)

## Proposed acceptance check

Use about 20 synthetic examples spanning isolated words, polyphonic characters, third-tone sequences, 一/不 sandhi, neutral syllables and ordinary sentences. Include pairs such as 银行/行业, 重庆/重量, 音乐/快乐 and 长大/长江. Establish the intended spoken reading separately from citation-tone spelling. Generate the same set twice per candidate and compare pronunciation errors, missing/repeated syllables, naturalness, generation delay and cost. ASR text matching alone cannot catch a wrong reading that still maps to the same Chinese character. Preview selected audio before any collection write.

For persistent Anki audio, generate once and cache a media file keyed by text, provider, model, voice, pronunciation hints and speed. This would make review playback independent of cloud latency and preserve the selected reading across clients. Realtime generation, bulk replacement and an audio-field/template migration are separate implementation choices.
